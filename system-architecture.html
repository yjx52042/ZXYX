架构说明

四层解耦架构：系统采用数据层、服务层、调度层、应用层四层架构设计，实现模块间的低耦合、高内聚。

本地离线部署：所有数据处理和模型推理均在本地完成，无需依赖云端服务。

不依赖云端：系统可在无网络环境下正常运行，保障数据安全和隐私。

数据层

  • NASA锂电池数据集
  • 用户上传CSV数据
  • 数据清洗
  • 归一化处理
  • 特征工程

服务层

  • Python模型推理
  • 随机森林
  • XGBoost
  • LSTM
  • GRU

调度层

  • Node.js
  • Express框架
  • RESTful API
  • 请求路由
  • 数据调度

应用层

  • HTML5
  • Tailwind CSS
  • 高德地图JS API
  • 3D可视化
  • 用户交互
